# X4 Supply Chain View (Mod)

## Summary

X4 mod that allows to view ware flow, stock levels, supply/demand ratios,
bottlenecks, ... across your station networks.

Download from [Nexusmods](https://www.nexusmods.com/x4foundations/mods/2371)

## Internationalization

The mod is primarily developed in English and automatically translated into all
default game languages. If you spot any translation issues, I'll gladly accept
pull requests.

## Declaration of AI usage

AI coding tools were used to build the mod as well as some game assets and
illustrations. The excellent [X4 Claude Modding
Tool](https://www.nexusmods.com/x4foundations/mods/2186) by ttyyygggg was used
for mod development. Only use if you are ok with this. Expect "claude-isms" in
code and comments!
